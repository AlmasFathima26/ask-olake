# Sync Modes

OLake supports full refresh, incremental sync, and change data capture (CDC).
The exact mode names, combinations, and prerequisites depend on the source
connector. For example, the official overview documents stateful resume for
Full Refresh + CDC and Full Refresh + Incremental & Strict CDC. Consult the
connector-specific documentation before configuring a job.
