# OLake Overview

OLake Go is an open-source data ingestion platform for replicating data from
databases, Kafka, and S3 into Apache Iceberg tables or plain Parquet files.
It supports full refresh, incremental, and change data capture (CDC) modes,
with the exact modes depending on the source connector.

OLake UI is a web interface for managing OLake Go jobs, sources, destinations,
and configuration. The official quickstart runs the UI, backend, and required
services using Docker Compose.

For current supported connectors, modes, destinations, and capabilities, see
the [OLake documentation](https://olake.io/docs/).
